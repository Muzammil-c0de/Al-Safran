# Public assets

Put your logo here as **`logo.png`** (transparent background works best).

- `logo.png` is used in the header, footer, admin page and as the browser tab icon.
- Recommended: about 400 × 400 px, or a wide logo around 600 × 200 px.
- Until the file is added, the site shows an "AS" text logo instead.
- If your logo image already contains the words "Al Safran", set
  `showNameNextToLogo: false` in `src/data/site.ts`.

Anything in this folder is served from the site root, e.g. `public/logo.png` → `/logo.png`.
